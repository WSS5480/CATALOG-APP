Set password

Stored as a one-way hash. It cannot be read back anywhere in this app, by anyone — tell them what it is, or tick the box above and let them choose their own.

🔒 There is no "view password" button, and there never will be. The server can check a password but cannot read one back. A forgotten password is replaced, never looked up — set a new one and tell them, or force a reset so they choose their own at the next sign-in.

Users

The people of this catalog. Location owners and group owners arrive automatically when the Locations & owners list below is loaded; add anyone else by hand. The same row feeds everything: sign-in, the groups used for access, and the Passwords tab. Stored in this app's own database.

Groups

Create groups first, then add people to them. Each group carries its own vendor access; everyone in it inherits, and a group inside another group inherits from its parent. A person's own setting overrides their groups.

People

One row per person, edited in place — groups, vendor access, tabs and budget, exactly like the group rows above. New people start with no groups and no password: tick them into groups here or above, and set the password on the Passwords tab.
